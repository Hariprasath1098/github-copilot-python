# Flask Sudoku

A Flask-backed Sudoku game with unique-solution puzzle generation, difficulty levels, hints, validation, a timer, scores, dark mode, and responsive styling.

## Setup

Create a virtual environment from the project directory:

```powershell
python -m venv .venv
```

Activate it in PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
```

Install dependencies:

```powershell
python -m pip install -r requirements.txt
```

## Tests

Run the full pytest suite with the project interpreter:

```powershell
.\.venv\Scripts\python.exe -m pytest -q
```

## Run the app

```powershell
.\.venv\Scripts\python.exe app.py
```
