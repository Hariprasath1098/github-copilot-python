# Project Guidelines

- Preserve existing functionality unless a change is explicitly required.
- Keep Flask backend, Sudoku logic, and frontend responsibilities separated.
- Prefer small, reusable functions.
- Keep code readable and maintainable.
- Avoid unnecessary dependencies.
- Add or update pytest tests for new features.
- Run the full pytest suite after feature changes.
- Ensure every generated puzzle has exactly one solution.
- Keep the UI responsive and accessible.
- Avoid unrelated changes.
